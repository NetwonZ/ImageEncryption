LaTeX 论文写作手册

新手快速入门指南 — 边写边查

0. 快速开始

LaTeX 是一个专业的排版系统，特别适合撰写包含大量数学公式和交叉引用的学术论文。本手册专为新手设计，涵盖论文写作的核心语法。

💡 提示：LaTeX 源文件是 .tex 后缀的纯文本文件，需要编译后生成 PDF。推荐使用 Overleaf（在线）或 TeXLive（本地）。

1. 文档基本结构

每个 LaTeX 文档都包含两部分：导言区（配置）和 正文区（内容）。

\documentclass[12pt, a4paper]{article}  % 文档类型和选项

% === 导言区：加载宏包和配置 ===
\usepackage{ctex}         % 中文支持
\usepackage{graphicx}    % 插入图片
\usepackage{amsmath}     % 数学公式增强

\title{论文标题}
\author{作者姓名}
\date{\today}          % 或指定日期

% === 正文区 ===
\begin{document}

\maketitle                  % 生成标题

这里是正文内容...

\end{document}

文档类说明适用场景
article短文章期刊论文、报告
report长报告技术报告、学位论文章节
book书籍完整书稿
ctexart中文文章中文论文（自动加载ctex）

2. 中文支持

撰写中文论文时，必须使用 ctex 宏包或 ctexart 文档类：

% 方法一：使用 ctex 宏包
\documentclass{article}
\usepackage{ctex}

% 方法二：直接使用中文文档类（推荐）
\documentclass{ctexart}   % 自动支持中文
💡 编译命令：使用 xelatex 或 pdflatex 编译含中文的文档。

5. 章节结构

LaTeX 提供层次化的章节命令：

\section{第一章}
这是第一章的内容。

\subsection{1.1 小节}
这是小节的内容。

\subsubsection{1.1.1 子小节}
这是子小节的内容。

\paragraph{段落标题} 段落内容...
\subparagraph{子段落} 更细分的内容...
💡 自动编号：章节会自动编号。如需取消编号，使用星号版本：\section*{无编号章节}

生成目录：

\tableofcontents  % 自动根据章节生成目录

7. 数学公式

7.1 行内公式与独立公式

% 行内公式：用 $ ... $ 包围
爱因斯坦质能方程 $E = mc^2$ 是物理学基础。

% 独立公式（不编号）：用 \[ ... \]
\[
  a^2 + b^2 = c^2
\]

% 独立公式（自动编号）：equation 环境
\begin{equation}
  f(x) = \frac{1}{\sqrt{2\pi}\sigma}
         e^{-\frac{(x-\mu)^2}{2\sigma^2}}
\end{equation}

7.3 矩阵与方程组

% 矩阵（需要 amsmath 宏包）
\begin{equation}
  A = \begin{bmatrix}   % bmatrix=方括号; pmatrix=圆括号; vmatrix=行列式
    1 & 2 & 3 \\
    4 & 5 & 6 \\
    7 & 8 & 9
  \end{bmatrix}
\end{equation}

% 多行公式对齐（& 对齐位置）
\begin{align}
  y &= ax^2 + bx + c \\
    &= a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}
\end{align}

% 方程组
\begin{equation}
  \begin{cases}
    x + y = 5 \\
    2x - y = 1
  \end{cases}
\end{equation}
💡 括号自适应大小：用 \left( 和 \right) 代替普通括号，括号会自动匹配内部公式的高度。

8. 列表

% 无序列表（bullet points）
\begin{itemize}
  \item 第一项内容
  \item 第二项内容
  \item 第三项内容
\end{itemize}

% 有序列表（自动编号）
\begin{enumerate}
  \item 第一步
  \item 第二步
  \item 第三步
\end{enumerate}

% 描述性列表
\begin{description}
  \item[方法A] 该方法的解释说明
  \item[方法B] 该方法的解释说明
\end{description}
💡 嵌套列表：列表内部可以再嵌套一层列表，例如在 \item 后再起一个 itemize。

9. 插入图片

需要 graphicx 宏包。图片（PNG/JPG/PDF）放在 .tex 文件同目录下。

% 单张图片
\begin{figure}[htbp]   % 位置：h当前 t顶部 b底部 p单独页
  \centering
  \includegraphics[width=0.8\textwidth]{图片文件名}
  \caption{图1：说明文字写在这里}
  \label{fig:example}
\end{figure}

% 在正文中引用该图：
如图~\ref{fig:example}所示，……

% 并排两图（各占45%宽度）
\begin{figure}[htbp]
  \centering
  \begin{minipage}{0.45\textwidth}
    \includegraphics[width=\textwidth]{图1}
    \caption{(a) 图1说明}
  \end{minipage}
  \hfill
  \begin{minipage}{0.45\textwidth}
    \includegraphics[width=\textwidth]{图2}
    \caption{(b) 图2说明}
  \end{minipage}
\end{figure}

11. 引用与交叉引用

LaTeX 可以自动管理章节、图表、公式的编号和引用。

% 第一步：为对象添加标签
\section{实验方法}
\label{sec:method}

\begin{equation}
  E = mc^2
  \label{eq:einstein}
\end{equation}

\begin{figure}[htbp]
  ...
  \label{fig:result}
\end{figure}

% 第二步：在正文中引用
在第~\ref{sec:method}节中，我们提出了……
如图~\ref{fig:result}所示，结果表明……
根据公式~\ref{eq:einstein}，能量与质量成正比。
💡 引用命名规范：推荐用前缀区分类型：sec: 章节、fig: 图、tab: 表、eq: 公式。

12. 参考文献

方法一：手动列表（简单论文）

\begin{thebibliography}{99}   % 99表示最多99条
  \bibitem{ref1} 张三, 李四. 论文标题[J]. 期刊名, 2024, 10(2): 1-10.
  \bibitem{ref2} Smith J, Doe A. Paper Title[C]//Conference Name. 2024: 100-110.
\end{thebibliography}

% 在正文中引用：
根据文献\cite{ref1}的研究，……
多个引用可以写在一起\cite{ref1, ref2}。

方法二：BibTeX（推荐，适合大论文）

BibTeX 将参考文献存在单独的 .bib 文件中，自动格式化。

第一步 创建 references.bib 文件：

@article{zhang2024deep,
  title={深度学习在图像识别中的应用},
  author={张三 and 李四},
  journal={计算机学报},
  volume={10},
  number={2},
  pages={1--10},
  year={2024}
}

@inproceedings{smith2024neural,
  title={Neural Network Optimization},
  author={Smith, John and Doe, Alice},
  booktitle={Proc. of ICML},
  pages={100--110},
  year={2024}
}

第二步 在 .tex 文件末尾添加：

% 正文中引用：
根据文献\cite{zhang2024deep}的研究，……

% 文档末尾：
\bibliographystyle{plain}  % 引用格式：plain/ieeetr/alpha/unsrt
\bibliography{references}     % 不带.bib后缀
⚠️ 编译顺序：使用 BibTeX 时需要多次编译：
1. pdflatex 文件名.tex
2. bibtex 文件名
3. pdflatex 文件名.tex（两次）

\tableofcontents
\newpage

\label{sec:intro}

\label{sec:method}

\begin{equation}
  x' = \frac{x - \mu}{\sigma}

16. 多文件分章管理

写较长的论文时，将每个章节放到独立的 .tex 文件中，再在主文件里引用，是一种非常实用的组织方式。这样每次只需打开对应章节文件写作，主文件负责整合和编译。

16.1 \input 与 \include 的区别

命令效果适用场景
\input{文件}原地插入内容，不分页，不受 \includeonly 影响导言区配置、共用宏定义、小片段
\include{文件}插入前后自动新起一页，支持 \includeonly 局部编译论文各章节（推荐）
💡 注意：\include 的文件名不能带 .tex 后缀，\input 则可带可不带。
例如：\include{chapters/intro}（✓） \include{chapters/intro.tex}（✗）

16.2 推荐目录结构

将章节文件统一放在 chapters/ 子文件夹中，图片放在 figures/，参考文献放在根目录：

my_thesis/                ← 整个项目根目录
├── main.tex              ← 主文件（唯一需要编译的文件）
├── references.bib        ← 参考文献数据库
├── chapters/             ← 章节文件夹
│   ├── abstract.tex      ← 摘要
│   ├── ch01_intro.tex    ← 第1章：引言
│   ├── ch02_related.tex  ← 第2章：相关工作
│   ├── ch03_method.tex   ← 第3章：研究方法
│   ├── ch04_experiment.tex
│   └── ch05_conclusion.tex
└── figures/              ← 图片文件夹
    ├── architecture.png
    └── results.pdf

主文件 main.tex 的写法

\documentclass[12pt, a4paper]{ctexart}

\usepackage{amsmath, graphicx, booktabs, hyperref}
\graphicspath{{figures/}}  % 告诉 LaTeX 在 figures/ 中找图片

\title{我的论文标题}
\author{作者姓名}
\date{\today}

\begin{document}

\maketitle
\tableofcontents
\newpage

% 引入各章节文件（自动在每章前后分页）
\include{chapters/abstract}
\include{chapters/ch01_intro}
\include{chapters/ch02_related}
\include{chapters/ch03_method}
\include{chapters/ch04_experiment}
\include{chapters/ch05_conclusion}

% 参考文献
\bibliographystyle{plain}
\bibliography{references}

\end{document}

章节文件示例（chapters/ch01_intro.tex）

章节文件只写正文内容，不需要 \documentclass 和 \begin{document}，直接从章节命令开始：

% 文件：chapters/ch01_intro.tex
% （不含 \documentclass 和 \begin{document}！）

\section{引言}
\label{sec:intro}

随着人工智能技术的飞速发展……

\subsection{研究背景}
近年来，深度学习在多个领域取得了突破性进展……

\subsection{本文贡献}
本文的主要贡献如下：
\begin{itemize}
  \item 提出了一种新的模型架构；
  \item 在多个基准数据集上验证了方法的有效性。
\end{itemize}
💡 图片路径：章节文件中引用图片时，路径相对于主文件所在目录，而非章节文件本身。例如在章节文件里写 \includegraphics{figures/arch.png} 是正确的，因为主文件在 my_thesis/，图片就在 my_thesis/figures/。

16.3 局部编译（只编译部分章节）

论文很长时，每次全量编译很慢。在导言区使用 \includeonly 可以只编译指定的章节，其他章节的编号和引用依然保持正确：

\documentclass{ctexart}
\usepackage{...}

% 只编译第3章和第4章，其余章节跳过但保留编号
\includeonly{chapters/ch03_method, chapters/ch04_experiment}

\begin{document}
  ...
  \include{chapters/ch01_intro}       % 跳过（不生成内容）
  \include{chapters/ch02_related}     % 跳过
  \include{chapters/ch03_method}      % ✓ 编译
  \include{chapters/ch04_experiment}  % ✓ 编译
  ...
\end{document}
⚠️ 注意：\includeonly 只对 \include 生效，对 \input 无效。写完某章后，删除或注释掉 \includeonly 行即可恢复全量编译。

编译时始终只编译 main.tex

无论你在哪个章节文件中写作，编译时始终运行主文件，不要直接编译章节文件：

# 正确：编译主文件
xelatex main.tex

# 错误：直接编译章节文件（会报错，因为章节文件没有 \documentclass）
xelatex chapters/ch01_intro.tex  ← 不要这样做
